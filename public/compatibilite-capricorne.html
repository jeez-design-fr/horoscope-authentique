COMPATIBILITÉ AMOUREUSE CAPRICORNE

Comment Capricorne s'entend avec chacun des 12 signes du zodiaque, en amour comme au quotidien : le résumé complet, signe par signe, avant de tester votre propre combinaison dans l'Oracle de Compatibilité.

Capricorne + Taureau — L'EMPIRE

98%

Au quotidien : Vous êtes faits du même bois. Travailleurs, ambitieux, patients. Vous construisez ensemble un patrimoine solide.

En amour : Profond et mature. Pas de chichi, mais une solidité à toute épreuve. Le Capricorne respecte la force tranquille du Taureau.

Sur la durée : Éternelle. C'est le couple qui fête ses noces de diamant. Rien ne peut vous ébranler.

Ce qui vous rapproche : L'ambition. Vous voulez tous les deux réussir et vous mettre à l'abri du besoin.

Le point épineux : Le pessimisme. Attention à ne pas transformer votre vie en une longue liste de devoirs et d'obligations.

Capricorne + Vierge — L'EMPIRE SOLIDE

98%

Au quotidien : Deux signes de Terre. Vous parlez le même langage : efficacité, économie, devoir. C'est une machine de guerre bien huilée.

En amour : Pas très démonstratif, mais d'une fiabilité absolue. Vous comptez l'un sur l'autre comme sur un roc.

Sur la durée : Indestructible. Vous vieillirez ensemble dans la sécurité et le confort.

Ce qui vous rapproche : Le réalisme. Pas de chimères ici, que du concret.

Le point épineux : L'austérité. N'oubliez pas de rire et de jouer un peu. La vie n'est pas qu'une to-do list.

Capricorne + Capricorne — LE SOMMET DE LA MONTAGNE

95%

Au quotidien : Sérieux, ambitieux, résistant. Vous formez une équipe de choc pour réussir socialement et matériellement.

En amour : Mature et profond. Vous n'avez pas besoin de mots pour savoir que l'autre est là.

Sur la durée : Indestructible. C'est un engagement total et réfléchi.

Ce qui vous rapproche : L'intégrité et la persévérance.

Le point épineux : La froideur. N'oubliez pas de mettre un peu de chaleur et de folie dans votre empire.

Capricorne + Scorpion — LES STRATÈGES

92%

Au quotidien : Vous êtes durs, résistants, ambitieux. Vous formez une alliance redoutable. Personne n'ose vous attaquer. C'est du sérieux.

En amour : Profond, fidèle, absolu. Vous n'avez pas besoin de parler pour vous comprendre. Vous vous respectez immensément.

Sur la durée : Indestructible. Une fois l'engagement pris, c'est pour la vie. Un couple de pouvoir.

Ce qui vous rapproche : L'exigence. Vous ne supportez pas la faiblesse ou la médiocrité.

Le point épineux : Le silence. Attention à ne pas vous murer dans un mutisme hautain.

Capricorne + Poissons — LA TERRE ET L'EAU

90%

Au quotidien : Le Capricorne offre un cadre, le Poissons le remplit de couleurs. Le Capricorne gère, le Poissons rêve. C'est un équilibre très apaisant.

En amour : Le Capricorne fond (en secret) pour la douceur du Poissons. Il se sent utile et protecteur. Le Poissons se sent en sécurité.

Sur la durée : Solide. Le Capricorne est le roc dont le Poissons a besoin pour ne pas dériver.

Ce qui vous rapproche : La profondeur. Vous ne parlez pas pour ne rien dire.

Le point épineux : Le pessimisme. Le Capricorne peut parfois broyer du noir et entraîner le Poissons avec lui.

Capricorne + Cancer — L'AXE DE LA FAMILLE

88%

Au quotidien : Opposés et complémentaires. Le Cancer est la Mère (douceur), le Capricorne est le Père (rigueur). Ensemble, vous bâtissez un empire familial solide.

En amour : Le Capricorne structure les émotions du Cancer. Le Cancer adoucit la froideur du Capricorne. C'est un équilibre parfait.

Sur la durée : Pour la vie. Vous avez les mêmes valeurs traditionnelles et le même sens de l'engagement.

Ce qui vous rapproche : La famille. C'est le pilier central de votre union.

Le point épineux : La froideur. Le Cancer a besoin de mots d'amour que le Capricorne a parfois du mal à prononcer.

Capricorne + Lion — L'AMBITION PARTAGÉE

75%

Au quotidien : Le Lion veut le prestige, le Capricorne veut le pouvoir. C'est un couple 'Power Couple'. Socialement, c'est une réussite totale.

En amour : Un peu froid. Le Capricorne peut éteindre l'enthousiasme du Lion par son réalisme. Le Lion trouve le Capricorne austère.

Sur la durée : Solide par intérêt commun. Vous construisez un empire, mais n'oubliez pas de vous aimer.

Ce qui vous rapproche : La réussite. Vous voulez tous les deux atteindre le sommet.

Le point épineux : La chaleur. Le Lion a besoin de démonstrations que le Capricorne juge inutiles.

Capricorne + Bélier — L'ÉLAN ET LE SOMMET

65%

Au quotidien : Le Bélier veut courir le sprint, le Capricorne court le marathon. Le Bélier trouve le Capricorne lent, le Capricorne trouve le Bélier immature.

En amour : Le Capricorne peut stabiliser le Bélier et l'aider à réussir. Le Bélier apporte la joie de vivre qui manque au Capricorne.

Sur la durée : C'est une alliance stratégique. Si vous avez un but commun (famille, entreprise), vous êtes imbattables.

Ce qui vous rapproche : L'ambition. Vous voulez tous les deux être les premiers, chacun à votre manière.

Le point épineux : L'autorité. Vous voulez tous les deux commander. Il faudra définir des territoires clairs.

Capricorne + Balance — LE SOCIAL ET LE SOLITAIRE

60%

Au quotidien : La Balance a besoin de monde, le Capricorne a besoin de silence. La Balance dépense pour l'esthétique, le Capricorne pour l'utile.

En amour : Le Capricorne est fasciné par l'élégance de la Balance mais la trouve frivole. La Balance trouve le Capricorne froid.

Sur la durée : Difficile. Vous ne partagez pas les mêmes plaisirs.

Ce qui vous rapproche : L'ambition sociale. Vous savez tous les deux vous tenir en société.

Le point épineux : La froideur. La Balance a besoin de mots d'amour que le Capricorne ne dit pas.

Capricorne + Sagittaire — L'OPTIMISTE ET LE RÉALISTE

60%

Au quotidien : Le Sagittaire dit 'Tout est possible !', le Capricorne répond 'Non, voici le budget'. Le Sagittaire veut courir, le Capricorne veut bâtir. C'est parfois frustrant.

En amour : Le Capricorne admire la joie du Sagittaire mais le trouve immature. Le Sagittaire trouve le Capricorne rabat-joie mais rassurant.

Sur la durée : Demandera des compromis. Le Sagittaire devra mûrir, le Capricorne devra sourire.

Ce qui vous rapproche : L'ambition. Vous voulez tous les deux aller haut et loin.

Le point épineux : Le temps. Le Sagittaire vit dans l'instant, le Capricorne vit dans la durée.

Capricorne + Verseau — LE VIEUX SAGE ET LE GÉNIE

50%

Au quotidien : Le Capricorne respecte les règles, le Verseau veut les briser. Le Capricorne aime le passé, le Verseau le futur. Difficile de s'accorder sur le présent.

En amour : Froid. Le Capricorne juge le Verseau irresponsable. Le Verseau juge le Capricorne coincé. Mais intellectuellement, vous vous respectez.

Sur la durée : Compliquée. Vos modes de vie sont souvent incompatibles.

Ce qui vous rapproche : L'indépendance d'esprit. Vous vous fichez du regard des autres.

Le point épineux : La chaleur. Votre relation manque cruellement de tendresse spontanée.

Capricorne + Gémeaux — LA CIGALE ET LA FOURMI

40%

Au quotidien : Le Gémeaux est un éternel adolescent, le Capricorne est né vieux. Le Gémeaux veut s'amuser, le Capricorne veut travailler.

En amour : Le Capricorne peut structurer le Gémeaux, mais il risque souvent de le juger sévèrement. Le Gémeaux trouve le Capricorne ennuyeux.

Sur la durée : Difficile. Vous n'avez pas les mêmes priorités dans la vie.

Ce qui vous rapproche : L'humour (parfois). Le Capricorne a un humour noir que le Gémeaux peut apprécier.

Le point épineux : La maturité. Le Capricorne demande une responsabilité que le Gémeaux refuse de porter.
