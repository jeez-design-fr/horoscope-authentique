COMPATIBILITÉ AMOUREUSE POISSONS

Comment Poissons s'entend avec chacun des 12 signes du zodiaque, en amour comme au quotidien : le résumé complet, signe par signe, avant de tester votre propre combinaison dans l'Oracle de Compatibilité.

Poissons + Scorpion — L'ÂME SŒUR SPIRITUELLE

98%

Au quotidien : Deux signes d'Eau. L'osmose est totale. Vous communiquez par ondes. C'est magique, mystique, enveloppant.

En amour : Inconditionnel. Vous vous devinez. Le Scorpion protège le Poissons, qui apaise le Scorpion.

Sur la durée : Éternelle. C'est le couple qui ne fait qu'un. La fusion dont vous rêvez tous les deux.

Ce qui vous rapproche : L'intuition. Vous ressentez les choses avec la même intensité.

Le point épineux : Les addictions. Attention à ne pas vous entraîner mutuellement vers le fond si ça va mal.

Poissons + Poissons — L'OCÉAN SANS FIN

98%

Au quotidien : Vous flottez. La réalité n'existe plus. C'est magique, intuitif, artistique. Attention aux factures impayées !

En amour : Spirituel et inconditionnel. Vous fusionnez totalement.

Sur la durée : Onirique. Vous vivez dans un rêve partagé.

Ce qui vous rapproche : La sensibilité et la compassion.

Le point épineux : Le chaos. Sans ancrage, vous risquez de vous perdre ensemble dans les illusions.

Poissons + Cancer — LE CONTE DE FÉES

95%

Au quotidien : Tout est fluide, doux, intuitif. Vous vivez dans un rêve éveillé. La réalité matérielle passe au second plan (attention aux factures !).

En amour : Romantique et spirituel. Vous vous devinez. C'est une communion des cœurs, tendre et bienveillante.

Sur la durée : Longue et paisible. Vous créez un refuge contre la dureté du monde.

Ce qui vous rapproche : La sensibilité. Vous pleurez devant les mêmes films et ressentez les mêmes vibrations.

Le point épineux : La fuite. Aucun de vous n'aime affronter les problèmes concrets. Risque de déni de réalité.

Poissons + Capricorne — LA TERRE ET L'EAU

90%

Au quotidien : Le Capricorne offre un cadre, le Poissons le remplit de couleurs. Le Capricorne gère, le Poissons rêve. C'est un équilibre très apaisant.

En amour : Le Capricorne fond (en secret) pour la douceur du Poissons. Il se sent utile et protecteur. Le Poissons se sent en sécurité.

Sur la durée : Solide. Le Capricorne est le roc dont le Poissons a besoin pour ne pas dériver.

Ce qui vous rapproche : La profondeur. Vous ne parlez pas pour ne rien dire.

Le point épineux : Le pessimisme. Le Capricorne peut parfois broyer du noir et entraîner le Poissons avec lui.

Poissons + Taureau — LE JARDIN D'ÉDEN

88%

Au quotidien : Le Taureau s'occupe du réel, le Poissons s'occupe du rêve. Le Taureau offre un cadre rassurant aux divagations du Poissons.

En amour : Romantique et sensuel. Le Taureau est touché par la fragilité du Poissons et veut le protéger.

Sur la durée : Harmonieuse. Vous créez votre petit monde à vous, loin de la dureté de la réalité.

Ce qui vous rapproche : La douceur. Vous cherchez tous les deux la paix et la beauté.

Le point épineux : Le manque de réalisme du Poissons peut parfois agacer le pragmatisme du Taureau.

Poissons + Vierge — L'AXE DU SERVICE

85%

Au quotidien : Opposés complémentaires. La Vierge organise le réel pour permettre au Poissons de rêver. Le Poissons apporte la magie qui manque à la Vierge.

En amour : La Vierge est touchée par la grâce du Poissons. Le Poissons se sent en sécurité avec la Vierge. C'est alchimique.

Sur la durée : Très bonne. Vous vous complétez : l'un a les pieds sur terre, l'autre la tête dans les étoiles.

Ce qui vous rapproche : Le dévouement. Vous aimez tous les deux aider et soigner.

Le point épineux : Le chaos. Si le Poissons est trop désorganisé, la Vierge devient tyrannique.

Poissons + Balance — LE ROMANTISME ABSOLU

75%

Au quotidien : C'est poétique, artistique, un peu déconnecté du réel. La Balance veut que ce soit beau, le Poissons veut que ce soit magique.

En amour : Tendre et sentimental. Vous vous écrivez des poèmes. Mais qui prend les décisions difficiles ?

Sur la durée : Floue. Vous risquez de flotter côte à côte sans direction précise.

Ce qui vous rapproche : L'amour de l'art et de la beauté.

Le point épineux : La réalité. Quand les problèmes arrivent, vous avez tous les deux tendance à fuir.

Poissons + Sagittaire — LES VOYAGEURS DE L'ÂME

75%

Au quotidien : Le Sagittaire voyage avec son corps, le Poissons avec son esprit. C'est un peu le bazar organisé. Vous vivez dans un monde à part, un peu déconnecté du réel.

En amour : Romantique et philosophique. Vous partagez des idéaux élevés. Mais le Sagittaire peut blesser le Poissons par sa franchise brutale.

Sur la durée : Fluctuante. Le Sagittaire risque de se lasser des jérémiades du Poissons.

Ce qui vous rapproche : La spiritualité. Vous cherchez tous les deux un sens à la vie.

Le point épineux : La réalité. Qui va gérer les papiers administratifs ? Aucun de vous deux.

Poissons + Verseau — LES EXTRA-TERRESTRES

65%

Au quotidien : Le Verseau est cérébral, le Poissons est émotionnel. Vous êtes tous les deux 'ailleurs', mais pas dans le même ailleurs. Le Verseau pense, le Poissons ressent.

En amour : Le Verseau est intrigué par le Poissons mais mal à l'aise avec ses débordements émotionnels. Le Poissons trouve le Verseau trop robotique.

Sur la durée : Floue. Vous avez du mal à vous saisir. C'est une relation insaisissable.

Ce qui vous rapproche : L'humanisme. Vous voulez tous les deux aider les autres.

Le point épineux : L'incompréhension émotionnelle. Le Poissons pleure, le Verseau analyse. Ça coince.

Poissons + Lion — LE HÉROS ET LA MUSE

60%

Au quotidien : Le Lion dirige, le Poissons suit (ou rêve). Le Lion protège ce signe fragile. Mais le Poissons est insaisissable pour le Lion direct.

En amour : Romantique. Le Lion est touché par la dévotion du Poissons. Mais attention aux désillusions.

Sur la durée : Inégale. Le Lion risque de se fatiguer de devoir tout gérer pendant que le Poissons plane.

Ce qui vous rapproche : Le rêve. Le Lion veut rendre la vie magique, le Poissons vit dans la magie.

Le point épineux : La réalité. Le Poissons fuit les responsabilités que le Lion finit par porter seul.

Poissons + Bélier — LE RÉEL ET L'IMAGINAIRE

50%

Au quotidien : Le Bélier fonce dans le tas, le Poissons nage en eaux troubles. Le Bélier ne comprend pas toujours les états d'âme du Poissons.

En amour : Le Bélier veut sauver et protéger ce Poissons si mystérieux. Le Poissons apporte une magie qui fascine le Bélier.

Sur la durée : Incertaine. Le Bélier risque de se lasser du flou artistique du Poissons, qui peut se sentir brutalisé.

Ce qui vous rapproche : L'intuition. Vous fonctionnez tous les deux à l'instinct, sans passer par la logique.

Le point épineux : La réalité. Le Bélier est dans l'action, le Poissons dans le rêve. Qui va payer les factures ?

Poissons + Gémeaux — LE MIRAGE

50%

Au quotidien : C'est flou. Le Gémeaux est logique, le Poissons est intuitif. Le Gémeaux ment par jeu, le Poissons ment par omission. On ne sait plus ce qui est vrai.

En amour : Le Gémeaux essaie de comprendre le Poissons, qui lui glisse entre les doigts. C'est insaisissable.

Sur la durée : Confuse. Beaucoup de malentendus possibles. Vous ne parlez pas la même langue.

Ce qui vous rapproche : La flexibilité. Vous êtes deux signes mutables, capables de vous adapter à tout.

Le point épineux : La cohérence. Votre couple manque de direction et de colonne vertébrale.
