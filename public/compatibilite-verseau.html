COMPATIBILITÉ AMOUREUSE VERSEAU

Comment Verseau s'entend avec chacun des 12 signes du zodiaque, en amour comme au quotidien : le résumé complet, signe par signe, avant de tester votre propre combinaison dans l'Oracle de Compatibilité.

Verseau + Gémeaux — LES ÂMES SŒURS MENTALES

98%

Au quotidien : Vous vous comprenez instantanément. Mêmes idées, même besoin de liberté, même vision du monde. C'est stimulant et électrique.

En amour : Une amitié amoureuse indestructible. Vous respectez totalement l'individualité de l'autre.

Sur la durée : Longue. Vous ne vous lasserez jamais de discuter ensemble.

Ce qui vous rapproche : L'originalité. Vous ne faites rien comme tout le monde et vous adorez ça.

Le point épineux : L'émotion. C'est tellement cérébral que vous pouvez oublier la tendresse physique. N'oubliez pas le corps.

Verseau + Balance — LES IDÉALISTES

98%

Au quotidien : Deux signes d'Air. Ça vole haut ! Discussions interminables, projets humanitaires, vie amicale riche. On respire.

En amour : Libre et intellectuel. Vous êtes les meilleurs amis du monde. Pas de jalousie, juste du partage.

Sur la durée : Parfaite. Vous vous comprenez sans effort. C'est fluide.

Ce qui vous rapproche : La communication. Vous avez toujours quelque chose à vous dire.

Le point épineux : L'intimité charnelle. N'oubliez pas de redescendre sur terre pour vous toucher.

Verseau + Sagittaire — LES AMIS DU MONDE

95%

Au quotidien : Génial ! Vous êtes indépendants, ouverts, tournés vers le futur. Pas de chaînes, pas de drames. Vous refaites le monde au petit-déjeuner.

En amour : Fraternel et stimulant. Vous vous aimez sans vous étouffer. C'est une relation moderne, basée sur la confiance absolue.

Sur la durée : Idéale. Vous ne vous lasserez jamais l'un de l'autre car vous évoluez sans cesse.

Ce qui vous rapproche : La liberté. C'est votre valeur cardinale à tous les deux.

Le point épineux : L'engagement. À force d'être libres, attention à ne pas devenir des étrangers qui se croisent.

Verseau + Bélier — LA LIBERTÉ CHÉRIE

92%

Au quotidien : Aucune routine ! Le Verseau a les idées du futur, le Bélier a l'énergie pour les réaliser. Vous respectez totalement l'indépendance de l'autre.

En amour : Original et stimulant. C'est une relation basée sur l'amitié amoureuse et la surprise permanente.

Sur la durée : Très bonne. Vous ne vous étouffez jamais. L'air du Verseau attise le feu du Bélier.

Ce qui vous rapproche : L'indépendance. Vous détestez tous les deux les chaînes et les obligations sociales.

Le point épineux : Le détachement. Le Bélier est passionné, le Verseau est cérébral. Parfois, le Bélier manquera de chaleur humaine.

Verseau + Verseau — LES VISIONNAIRES

92%

Au quotidien : Vous vivez dans le futur. Vous refaites le monde. C'est une colocation intellectuelle de haut vol. Liberté totale.

En amour : Cérébral. Vous êtes avant tout des meilleurs amis. L'amour est un concept que vous réinventez.

Sur la durée : Fluide. Pas de chaînes, pas de drames.

Ce qui vous rapproche : L'idéalisme et l'originalité.

Le point épineux : L'intimité émotionnelle. C'est parfois un peu trop froid et distant.

Verseau + Lion — L'AXE DE L'IDENTITÉ

85%

Au quotidien : Opposés polaires. Le Lion est 'Moi', le Verseau est 'Nous'. Le Lion est personnel, le Verseau est universel. Vous vous fascinez.

En amour : Le Verseau trouve le Lion un peu trop théâtral mais attachant. Le Lion est intrigué par la liberté du Verseau.

Sur la durée : Enrichissante. Le Verseau apprend au Lion à être moins égoïste, le Lion apprend au Verseau à avoir du cœur.

Ce qui vous rapproche : L'individualité. Vous ne voulez ressembler à personne d'autre.

Le point épineux : L'ego. Le Lion veut être le centre du monde du Verseau, qui refuse d'avoir un centre.

Verseau + Poissons — LES EXTRA-TERRESTRES

65%

Au quotidien : Le Verseau est cérébral, le Poissons est émotionnel. Vous êtes tous les deux 'ailleurs', mais pas dans le même ailleurs. Le Verseau pense, le Poissons ressent.

En amour : Le Verseau est intrigué par le Poissons mais mal à l'aise avec ses débordements émotionnels. Le Poissons trouve le Verseau trop robotique.

Sur la durée : Floue. Vous avez du mal à vous saisir. C'est une relation insaisissable.

Ce qui vous rapproche : L'humanisme. Vous voulez tous les deux aider les autres.

Le point épineux : L'incompréhension émotionnelle. Le Poissons pleure, le Verseau analyse. Ça coince.

Verseau + Vierge — LA LOGIQUE ET LE GÉNIE

60%

Au quotidien : La Vierge est méthodique, le Verseau est chaotique. La Vierge suit les règles, le Verseau les casse. C'est perturbant.

En amour : Cérébral. Vous échangez beaucoup d'idées, mais le Verseau est trop imprévisible pour la Vierge anxieuse.

Sur la durée : Instable. La Vierge finira par s'épuiser à essayer de ranger la vie du Verseau.

Ce qui vous rapproche : L'intelligence. Vous avez l'esprit vif tous les deux.

Le point épineux : L'imprévu. Le carburant du Verseau est le poison de la Vierge.

Verseau + Scorpion — LE REBELLE ET LE RÉVOLUTIONNAIRE

60%

Au quotidien : Le Scorpion veut fusionner, le Verseau veut se détacher. Le Scorpion est intense, le Verseau est froid. Ça coince.

En amour : Le Scorpion veut posséder l'âme du Verseau, qui est insaisissable. Cela rend le Scorpion fou.

Sur la durée : Toxique ou brève. Le Verseau finira par partir pour respirer.

Ce qui vous rapproche : L'anticonformisme. Vous aimez tous les deux choquer le bourgeois.

Le point épineux : La liberté. Le besoin d'air du Verseau est une insulte pour l'amour fusionnel du Scorpion.

Verseau + Capricorne — LE VIEUX SAGE ET LE GÉNIE

50%

Au quotidien : Le Capricorne respecte les règles, le Verseau veut les briser. Le Capricorne aime le passé, le Verseau le futur. Difficile de s'accorder sur le présent.

En amour : Froid. Le Capricorne juge le Verseau irresponsable. Le Verseau juge le Capricorne coincé. Mais intellectuellement, vous vous respectez.

Sur la durée : Compliquée. Vos modes de vie sont souvent incompatibles.

Ce qui vous rapproche : L'indépendance d'esprit. Vous vous fichez du regard des autres.

Le point épineux : La chaleur. Votre relation manque cruellement de tendresse spontanée.

Verseau + Taureau — LA TRADITION ET LE FUTUR

40%

Au quotidien : Le Taureau aime que rien ne change, le Verseau veut tout révolutionner. Le Taureau est prévisible, le Verseau est un chaos organisé.

En amour : Le Verseau intrigue le Taureau, mais il est souvent trop insaisissable pour lui. Le Taureau peut étouffer le Verseau.

Sur la durée : Compliquée. Vous vivez sur deux échelles de temps différentes.

Ce qui vous rapproche : L'obstination. Vous êtes deux signes fixes : quand vous avez une idée, vous ne la lâchez pas.

Le point épineux : L'engagement. Le Taureau veut fusionner, le Verseau veut garder son indépendance. Dialogue de sourds.

Verseau + Cancer — LE PASSÉ ET LE FUTUR

40%

Au quotidien : Le Cancer est nostalgique et attaché aux souvenirs. Le Verseau est tourné vers l'avenir et le progrès. Le Cancer est collant, le Verseau est distant.

En amour : Le Verseau intrigue le Cancer par son originalité, mais il ne comble pas son besoin de sécurité affective.

Sur la durée : Compliquée. Le Cancer risque de souffrir du détachement émotionnel du Verseau.

Ce qui vous rapproche : L'humain. Le Verseau aime l'humanité, le Cancer aime les humains. Nuance importante.

Le point épineux : L'intimité. Le Cancer veut fusionner, le Verseau veut respirer. Dialogue de sourds fréquent.
