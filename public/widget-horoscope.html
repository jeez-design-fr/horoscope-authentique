Pour les blogs et les sites

Ajoutez l’horoscope du jour à votre site

Un encadré élégant, mis à jour chaque matin, avec l’horoscope des douze signes écrit par Madeleine. Gratuit, sans inscription, à copier-coller en dix secondes.

Aperçu

Le code à copier

<div class="horoscope-authentique" data-signe="belier"></div>
<script src="https://www.horoscope-authentique.fr/widget/horoscope.js" async></script>
<p style="font-size:13px">Horoscope du jour offert par <a href="https://www.horoscope-authentique.fr/">Horoscope Authentique</a></p>

Le widget est-il vraiment gratuit ?+

Oui, entièrement. Il suffit de garder la petite mention « Horoscope du jour offert par Horoscope Authentique » sous l’encadré.

Le texte se met-il à jour tout seul ?+

Oui. Chaque matin, le widget affiche automatiquement le nouvel horoscope du jour, sans rien faire de votre côté.

Peut-on choisir le signe affiché ?+

Oui : remplacez « belier » par le signe voulu dans le code (taureau, gemeaux, cancer, lion, vierge, balance, scorpion, sagittaire, capricorne, verseau, poissons). Le visiteur peut aussi changer de signe dans le menu du widget.
